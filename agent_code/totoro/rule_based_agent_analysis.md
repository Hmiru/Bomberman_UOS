# Rule-Based Agent 분석

## 핵심 전략

### 1. 목표 우선순위 (Targeting System)
Rule-based agent는 다음 순서로 목표를 설정합니다:
1. **코인** (coins) - 최우선 수집 목표
2. **막다른 길** (dead_ends) - 폭탄 설치 최적 위치
3. **상자** (crates) - 파괴하여 코인 획득 가능
4. **적 에이전트** (enemies) - 조건부로 추적
   - `ignore_others_timer <= 0`일 때만 적극적으로 추적
   - 코인과 상자가 없을 때는 항상 추적

### 2. 이동 알고리즘
- **BFS (Breadth-First Search)** 사용 (`look_for_targets` 함수)
- 목표까지의 최단 경로 탐색
- 도달 불가능한 경우, 가장 가까운 지점으로 이동

### 3. 폭탄 설치 조건
폭탄을 설치하는 상황:
1. **막다른 길에 도착** - 효율적인 파괴를 위해
2. **적과 인접** (맨해튼 거리 1 이하)
3. **목표 도달 + 상자 인접** - 상자 파괴 목적
4. **최근 같은 위치에 폭탄 설치 안 함** (bomb_history 체크)

### 4. 회피 메커니즘
- **폭탄 회피**: 
  - 폭탄과 같은 선상에 있고 거리 < 4일 때 도망
  - 가능하면 코너를 돌아 안전 확보
- **폭발 지도** (bomb_map) 계산:
  - 각 타일의 폭발 예정 시간 추적
  - 안전한 타일만 이동 가능 영역으로 설정

### 5. 루프 방지
- **coordinate_history**: 최근 20개 위치 기록
- 같은 위치 3회 이상 방문 시 `ignore_others_timer = 5` 설정
- 일시적으로 적 추적 중단하여 루프 탈출

## 주요 약점 및 공략 포인트

### 1. 예측 가능한 행동 패턴
- BFS 기반이므로 항상 최단 경로 선택
- 목표 우선순위가 고정되어 있음

### 2. 팀 플레이 미지원
- **동료 인식 없음**: line 103에서 자신과 같은 이름의 에이전트만 제외
- 팀원과의 협력 전략 부재
- 팀킬 가능성 있음

### 3. 단순한 전투 전략
- 적과 인접 시 무조건 폭탄 설치
- 적의 폭탄 회피 패턴 예측 못함
- 전략적 폭탄 배치보다는 반응적 대응

### 4. 제한적인 상황 인식
- 미래 상태 예측 없음 (1스텝 앞만 고려)
- 연쇄 폭발 활용 못함
- 적의 이동 경로 예측 없음

### 1. 팀 인식 활용
```python
# rule_based는 팀을 구분 못하므로, 팀 전략으로 압도
# 예: 한 명이 유인, 다른 한 명이 매복
```

### 2. 예측 가능성 악용
- Rule-based의 BFS 경로를 예측
- 그 경로에 폭탄 설치하여 함정 구성

### 3. 루프 유도
- Rule-based를 막다른 곳으로 유인
- coordinate_history를 악용하여 비효율적 행동 유도

### 4. 폭탄 타이밍 활용
- Rule-based는 폭탄 타이머가 낮을 때만 회피
- 연쇄 폭발로 예상치 못한 공격 가능

### 5. 목표 조작
- 코인 위치를 이용한 유인
- 가짜 목표로 이끌어 함정에 빠뜨리기

## 코드 레벨 분석

### 핵심 함수
1. **look_for_targets**: BFS 경로 탐색
2. **act**: 메인 의사결정 로직
3. **reset_self**: 라운드별 초기화

### 상태 관리
- `bomb_history`: 최근 5개 폭탄 위치
- `coordinate_history`: 최근 20개 이동 위치  
- `ignore_others_timer`: 적 무시 타이머

### 행동 결정 프로세스
1. 유효한 행동 계산 (valid_actions)
2. 기본 행동 제안 생성 (action_ideas)
3. 목표 설정 및 경로 탐색
4. 폭탄 설치 조건 체크
5. 회피 행동 추가
6. 마지막 유효한 행동 선택

이 분석을 바탕으로 Totoro agent는 rule-based의 약점을 공략하면서 팀 플레이의 강점을 최대한 활용해야 합니다.
